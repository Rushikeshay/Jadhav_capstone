# Gondan Diaries  

Gondan Diaries is a travel journaling and social sharing web application built with Ruby on Rails. It allows users to document their trips, reflect on their experiences, and share memories with friends through a timeline-based interface.

The app combines structured trip tracking with AI-powered reflections to help users meaningfully revisit their travel experiences.

---

## Features  

- Create and manage multiple trips  
- Organize trips into multiple days with detailed activities  
- Add photos to each day and post them to a shared timeline  
- Social features: add friends, like posts, and comment on shared memories  
- Personalized travel diary entries for each day  
- AI-powered reflection prompts using OpenAI API (3 guided questions per entry)  
- Interactive maps to visualize trips and locations using Google Maps API  

---

## Tech Stack  

- **Backend:** Ruby on Rails  
- **Frontend:** HTML, CSS, JavaScript (Rails views)  
- **APIs:**  
  - OpenAI API (for reflection questions and diary prompts)  
  - Google Maps API (for location and trip visualization)  
- **Database:** Supabase 
- **Deployment:** Render  

---

## Purpose  

This project was built to explore full-stack web development with Ruby on Rails while integrating external APIs to enhance user experience. The goal was to create a meaningful travel journaling platform that blends social features with AI-assisted reflection.
